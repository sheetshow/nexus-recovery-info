Nexus Recovery

A personal, single-user utility for encrypted backups of selected local work.

What it does

The utility runs on the owner's computer. It uses restic to encrypt selected files and rclone to store the encrypted backup repositories in the owner's Google Drive.

Google Drive access

The owner-controlled connection requests only access to files created or explicitly opened with this app (drive.file). It does not request general access to the owner's entire Drive.

This website is informational. It has no sign-in form and cannot browse, upload, download, or restore private backups. The backup utility is not a public backup service.
